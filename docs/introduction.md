## Introduction

@zeus akin is a Filament theme focused on a clean look with improved default icons and a sidebar-first layout.

**[Github](https://github.com/lara-zeus/akin) · [Packagist](https://packagist.org/packages/lara-zeus/akin) · [Discord](https://discord.com/channels/883083792112300104)**

## Features

- Simple theme close to Filament defaults
- Better default icon set
- Sidebar-focused UI style
