## Installation

### composer

```bash
composer require lara-zeus/akin
```

### register the plugin in your panel:

```php
->plugins([
    \LaraZeus\Akin\AkinTheme::make(),
])
```

### add this to your custom theme

```css
@import '/vendor/lara-zeus/akin/resources/css/theme.css';
```
